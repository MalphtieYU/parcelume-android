# 产品定义（MVP）

## 一句话定位

Parcelume 是一款无需手动记账、通过本机通知自动整理包裹的 Android 助理。

## 核心体验

用户安装并完成一次系统授权后继续正常购物。Parcelume 在后台从用户选定的购物与快递应用通知中提取必要信息，并在需要取件、物流异常或用户主动查看时呈现结果。

## 不做什么

- 不读取购物应用数据库
- 不使用无障碍服务抓取页面
- 不要求用户输入购物平台密码
- 不上传完整通知内容
- 不在首版接入广告和用户画像
- 不把“快递已签收”自动当作“用户已取件”

## 成功标准

首轮测试重点不是 UI 完整度，而是以下三个指标：

1. 真实物流通知的发现率。
2. 状态、运单号和取件码的识别准确率。
3. 同一包裹的多条通知能否正确合并。

## 数据生命周期

- 活跃状态：待发货、已发货、运输中、派送中、待取件、已送达、异常。
- 可清理状态：仅“已取件”或用户主动归档。
- 保留策略：一周、一个月、一年、永久。
- 默认策略：永久，避免用户未明确选择时丢失数据。
- 删除方式：每日后台检查，以完成时间为基准删除过期记录。

## 隐私设计

- 来源默认全部关闭，由用户逐项开启。
- 通知内容在内存中解析，不保存原始正文。
- 数据库仅保存提取后的必要字段。
- 首版 Manifest 不申请网络权限。
- 用户可以在设置中一键删除全部本地数据。
