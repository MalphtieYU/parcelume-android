# 产品定义（0.2 Preview）

## 一句话定位

Parcelume 是一款在用户浏览购物平台订单与物流页面时，本地识别必要字段并统一整理包裹的 Android 助理；通知只是可选补充。

## 核心体验

用户选择允许识别的平台，阅读独立的敏感权限说明，并在 Android 系统中亲自开启页面识别。之后继续正常购物或查看订单：出现下单成功、订单详情、物流详情、待取件等受支持页面时，Parcelume 在后台静默提取结构化字段，不弹出自己的界面。

## 当前明确不做什么

- 不读取购物应用的私有数据库或账号凭据。
- 不代替用户点击、滚动、输入或自动跳转页面。
- 不截屏，不保存页面树和原始页面文字。
- 不上传订单、通知或包裹数据。
- 0.2 不提供实时联网物流查询，也不承诺绝不遗漏。
- 不把“快递已签收”自动当作“用户已取件”。

## 成功标准

1. 普通商城首页不会产生记录，订单与物流页面才进入解析。
2. 商品标题、订单号、运单号、取件码和状态尽量准确提取。
3. 同一来源的订单页面与后续物流页面可以按订单号或运单号合并。
4. 原始页面与通知正文不落盘，未选来源立即忽略。

## 数据生命周期

- 活跃状态：待发货、已发货、运输中、派送中、待取件、已送达、异常。
- 可清理状态：仅“已取件”或用户主动归档。
- 保留策略：一周、一个月、一年、永久；默认永久。
- 删除方式：每日后台检查，以完成时间为基准删除过期记录，也可一键删除全部本地数据。

## 下一阶段

在真实购物页面完成脱敏兼容性测试后，再选择合规物流 provider，实现由用户主动开启的联网追踪。届时产品应保持“本地优先”，而不能继续声称“完全离线”。
